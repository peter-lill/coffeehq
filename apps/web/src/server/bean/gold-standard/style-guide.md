# GS-001 — File Note Style Guide

Version: 1.0

## Purpose

A file note is a concise, objective and accurate record that allows the next Claims Representative to understand why the interaction occurred, what material information was obtained, what advice was provided, what changed and what remains outstanding.

Do not reproduce the conversation. Record the claim-management outcome.

## Audience

Write for the next Claims Representative managing the claim.

## Core principles

- Evidence first. Do not invent, assume or overstate.
- Record outcomes, not dialogue.
- Include only material information.
- Present events in a logical chronology rather than transcript order.
- Use neutral, professional and plain language.
- Avoid duplication and conversational filler.
- Produce text ready to paste into CPIS.

## Naming

- Worker: full name at first reference, first name thereafter.
- Employer representatives: position or title unless a name is needed for clarity.
- Doctors and practitioners: professional title and surname.
- Witnesses: full name at first reference, first name thereafter.
- Claims Representative: do not write in the third person. Use concise constructions such as `Advised worker...` or `Explained...`.

## Dates

Use Australian format: DD/MM/YYYY.

## Tone

Professional, neutral, factual and concise. Do not advocate, speculate, diagnose or embellish.

## Definition of excellence

A Gold Standard file note accurately reflects the interaction, omits immaterial detail, clearly identifies outcomes and actions, and requires little or no editing before entry into CPIS.
