# ADR-007 — Structured claims data before RFD intelligence

**Status:** Accepted  
**Date:** 18 July 2026

## Context

CoffeeOS handles sensitive claims evidence and requires clear boundaries before further feature development.

## Decision

RFD generation will rely on approved structured factors, issues, evidence propositions, medical opinions, findings, procedural fairness and decision versions rather than free-text documents alone.

## Consequences

- New code must conform to this decision.
- Exceptions require a superseding ADR.
- Tests and documentation must demonstrate the decision where applicable.
