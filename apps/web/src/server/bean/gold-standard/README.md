# BEAN Gold Standard

Versioned writing standards used by CoffeeHQ to generate CPIS-ready WorkCover file notes.

## Source of truth

- `style-guide.md` — purpose, audience, tone and naming conventions
- `writing-rules.md` — sentence construction, materiality and omission rules
- `phrase-library.md` — preferred professional wording
- `section-selection.md` — when sections are included or omitted
- `reviewer-checklist.md` — quality gate applied before output
- `interactions/` — interaction-specific guidance
- `examples/` — approved transcript/file-note pairs

Writing standards must be changed here rather than embedded in TypeScript prompts. Changes should be versioned and regression-tested against approved examples.
